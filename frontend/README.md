# Mendadak Outdoor E-Commerce

Platform e-commerce perlengkapan mendaki, kemping, dan petualangan outdoor berbasis Next.js dan Express.js.

## 🛠️ Stack Teknologi
* **Frontend:** Next.js (App Router), React, TypeScript, Tailwind CSS
* **Backend:** Node.js, Express.js, Prisma ORM, PostgreSQL
* **State Management & Storage:** React Hooks, LocalStorage
